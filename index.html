Featured project · Final course project 2026

WishBound

A web and mobile application platform for collecting virtual characters. Players pull from limited-time banners, build a collection, and grow friendship levels with their favourite characters.

How it's built

  • ASP.NET Core Web API with pulls, a pity system, inventory, currencies and events
  • SQL Server database modelled from user-case, ER and class diagrams
  • Admin tools to manage accounts, with every action saved to an audit log
  • Web client in HTML, CSS, and JavaScript with a companion character on Home
  • .NET MAUI mobile app with daily rewards and push notifications
