Featured project · Final course project 2026

WishBound

A web and mobile platform for collecting virtual characters. Players pull from limited-time banners, build a collection, and grow friendship levels with their favourite characters. I designed it end to end, from the ER model to the admin dashboard.

How it's built

A REST API serves two clients: a browser app and a native mobile app.

  • apiASP.NET Core Web API with pulls, a pity system, inventory, currencies and events
  • dbSQL Server database modelled from use-case, ER and class diagrams
  • apiAdmin tools to manage accounts, with every action saved to an audit log
  • uiWeb client in HTML, CSS and JavaScript with a companion character on Home
  • ui.NET MAUI mobile app with daily rewards and push notifications
